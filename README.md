# Roccolino

Applicazione interna per lo staff del ristorante Roccolino.

## Obiettivo

Gestire da iPhone, Android e PC:

- prenotazioni clienti;
- mappa dei tavoli;
- disponibilità dei posti;
- targhe per accesso ZTL;
- note operative dello staff.

## Stack iniziale

- React
- Vite
- PWA installabile
- database e autenticazione da collegare nella fase successiva

## Avvio locale

```bash
npm install
npm run dev
```

## Stato

Prima struttura funzionante con dashboard, prenotazioni dimostrative, tavoli e targhe ZTL.
